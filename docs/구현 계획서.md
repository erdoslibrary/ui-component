# 📌 UI 컴포넌트 & UX 레이어 쇼케이스 — 후속 구현 계획서

> **작성 일시**: 2026-10-17  
> **기준 브랜치**: `feat/ui` (커밋: `3499c17`)  
> **문서 목적**: 직전 세션에서 완료된 Lucide 아이콘 표준화에 이어, 메인 카탈로그(`index.html`)의 완전한 일관성 확보 및 Anti-AI-Slop 규칙 준수, 브라우저 QA 검증을 위한 상세 실행 계획을 정의합니다.

## 1. 개요 및 추진 배경

1. **현 상태 스냅샷**:
   - `ui-kit-playground.html` 및 `js/data/ux-layers.js`에는 Lucide 벡터 아이콘 시스템과 Anti-AI-Slop 미니멀 스타일(1px solid border, 무채색 베이스)이 적용 완료되었습니다.
   - `js/vendor/lucide.min.js`가 로컬 벤더로 추가되어 외부 CDN 의존성 없이 독립 실행이 가능합니다.
   - 메인 카탈로그 진입점인 `index.html`에는 여전히 일부 유니코드 이모지/특수문자(☰, 🔍, ☀️, 📖, 💡, 🎯, 📋 등)가 남아 있어 시각적 언어 통일 및 Anti-AI-Slop 규칙 준수를 위한 정리가 필요합니다.

2. **최종 목표**:
   - `index.html`의 모든 시각 요소를 Lucide 벡터 아이콘으로 통일
   - Anti-AI-Slop 규칙(장식 배제, 그라데이션/컬러 그림자 금지, 150ms 이하 상태 전이) 전수 감사
   - 32개 표준 UI 컴포넌트 및 8개 UX 레이어에 대한 브라우저 종합 인터랙션 QA 수행
   - 안정적이고 독립적인 정적 쇼케이스 배포 상태 확보

## 2. 세부 구현 단계 (4단계 로드맵)

### Phase 1. `index.html` 및 `js/app.js` Lucide 아이콘 표준화

#### 1.1 `index.html` 마크업 개편
- **스크립트 추가**: `<script src="js/vendor/lucide.min.js"></script>` 로드 (`index.html` 상단 또는 하단)
- **헤더 바 (Global Navigation)**:
  - 모바일 메뉴 버튼: `☰` ➔ `<i data-lucide="menu"></i>`
  - 검색창 아이콘: `🔍` ➔ `<i data-lucide="search"></i>`
  - 검색창 초기화 버튼: `✕` ➔ `<i data-lucide="x"></i>`
  - 테마 토글 버튼: `☀️ 라이트` ➔ `<i data-lucide="sun" id="themeToggleIcon"></i><span id="themeToggleText">라이트</span>`
  - 용어 사전 링크: `📖 Glossary` ➔ `<i data-lucide="book-open"></i><span>Glossary</span>`
- **사이드바 네비게이션**:
  - `⚡ UX 필수 공통 레이어` ➔ `<i data-lucide="layers"></i><span>UX 필수 공통 레이어</span>`
  - `📚 32가지 UI 컴포넌트` ➔ `<i data-lucide="layout-grid"></i><span>32가지 UI 컴포넌트</span>`
- **스펙 & 가이드 토글 영역**:
  - 스펙 토글 탭: `💡 스펙 & 가이드` / `▾` ➔ `<i data-lucide="info"></i><span>스펙 & 가이드</span><i data-lucide="chevron-down" class="spec-tab-arrow"></i>`
  - 권장 사용처: `🎯 권장 사용처` ➔ `<i data-lucide="target"></i> 권장 사용처`
  - 핵심 UX 특징: `✨ 핵심 UX 특징` ➔ `<i data-lucide="sparkles"></i> 핵심 UX 특징`
  - 웹 접근성: `♿ 웹 접근성` ➔ `<i data-lucide="shield-check"></i> 웹 접근성`
- **라이브 프리뷰 툴바 (Viewport Controls)**:
  - 데스크톱: `🖥️ Desktop` ➔ `<i data-lucide="monitor"></i><span>Desktop</span>`
  - 태블릿: `📟 Tablet` ➔ `<i data-lucide="tablet"></i><span>Tablet</span>`
  - 모바일: `📱 Mobile` ➔ `<i data-lucide="smartphone"></i><span>Mobile</span>`
  - 새로고침: `🔄` ➔ `<i data-lucide="rotate-ccw"></i>`
- **코드 복사 버튼 (Code Panels)**:
  - HTML 복사: `📋 HTML 복사` ➔ `<i data-lucide="copy"></i><span>HTML 복사</span>`
  - CSS 복사: `📋 CSS 복사` ➔ `<i data-lucide="copy"></i><span>CSS 복사</span>`
  - JS 복사: `📋 JS 복사` ➔ `<i data-lucide="copy"></i><span>JS 복사</span>`
  - 전체 번들 복사: `📋 전체 번들 복사` ➔ `<i data-lucide="copy"></i><span>전체 번들 복사</span>`
  - 글로벌 토스트: `✓ 복사되었습니다!` ➔ `<i data-lucide="check"></i> <span>복사되었습니다!</span>`

#### 1.2 `js/app.js` 및 `css/main.css` 로직 보강
- 컴포넌트 렌더링 직후 `lucide.createIcons()` 호출 보장
- 테마 토글 시 `sun` ↔ `moon` 아이콘 동적 교체 로직 구현
- 코드 복사 완료 피드백 시 복사 버튼의 `copy` 아이콘을 1.5초간 `check` 아이콘으로 전환하는 마이크로 인터랙션 구현
- `css/main.css` 내 Lucide 아이콘의 정렬(`inline-flex`, `vertical-align: middle`, `stroke-width: 2px`) 기본 스타일 반영

### Phase 2. Anti-AI-Slop 스타일 전수 자가 점검 및 정리

`.claude/rules/anti-ai-slop.md` 규칙에 따른 스타일 전수 검사 및 제거:

1. **그라데이션(Gradient) 제거 검사**:
   - `css/main.css`, `css/theme.css`, `css/components.css` 내 `linear-gradient`, `radial-gradient` 전수 검색 및 단색/보더 대체
2. **글로우 및 컬러 그림자 제거**:
   - 색상이 들어간 `box-shadow` 또는 `blur ≥ 20px` 확인
   - `0 1px 2px rgba(0, 0, 0, 0.06)` 중성 회색 단일 계조로 통일
3. **글래스모피즘(`backdrop-filter`) 배제**:
   - 불필요한 블러 대신 불투명 배경(`var(--bg-surface)`) + `1px solid var(--border)`로 구획 명확화
4. **장식 모션 정돈**:
   - hover 시 `transform: scale()`, 키프레임 `shimmer`, `float` 등 불필요한 장식 애니메이션 제거
   - 상태 변경 전이는 150ms 이하의 색/투명도 변화로 한정
